1. Что такое «макросы» в языке C++?
Макросы — это механизм препроцессора, позволяющий задать именованные фрагменты кода, которые заменяются на своё содержимое перед компиляцией. Они создаются с помощью директивы #define.

2. Виды макросов в C++
Объектные макросы — просто заменяют имя на заданный текст.
Пример: #define PI 3.1415

Функциональные макросы — принимают параметры, похожи на функции.
Пример: #define SQUARE(x) ((x)*(x))

Цепочки макросов — макросы, вызывающие другие макросы.

Условные макросы — используются с #ifdef, #ifndef, #undef и т.д.

4. Что такое функциональный макрос?
Это макрос, который принимает аргументы и выглядит как вызов функции.
Пример:
#define MAX(a, b) ((a) > (b) ? (a) : (b))



5. Предопределённые макросы. __LINE__
Стандартные предопределённые макросы встроены в компилятор.
__LINE__ заменяется на номер текущей строки исходного файла.
Пример:
#include <iostream>
using namespace std;

int main() {
    cout << "Эта строка находится на линии " << __LINE__;
    return 0;
}

6. Строкофицирующий оператор #
Превращает аргумент макроса в строковой литерал.

cpp
#include <iostream>
#define STR(x) #x

int main() {
    std::cout << STR(Hello World);
    return 0;
}

7. Оператор конкатенации ##
Склеивает два токена в один.

cpp
#include <iostream>
#define CONCAT(a, b) a ## b

int main() {
    int var123 = 42;
    std::cout << CONCAT(var, 123);
    return 0;
}
