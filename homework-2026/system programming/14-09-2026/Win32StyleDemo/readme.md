Мини-инструкция по запуску
Подготовка
Убедитесь, что установлен .NET SDK (8.0 или новее) и Visual Studio Code с расширением C#.

Откройте папку решения Win32StyleDemo в VS Code.

Запуск первого приложения (окно с элементами)
Откройте терминал (Ctrl+``).

Выполните команду:

bash
dotnet run --project AppWithControls
Дождитесь появления окна с заголовком «Приложение с элементами управления». Не закрывайте окно.

Запуск второго приложения (изменение стилей)
Откройте новый терминал (значок + на панели терминалов или Terminal → New Terminal).

Выполните команду:

bash
dotnet run --project StyleChanger
Программа найдёт окно первого приложения по классу MyAppMainWindowClass и изменит стили дочерних элементов (кнопки, текстового поля, статического текста).

Проверка
После выполнения второго приложения внешний вид элементов в первом окне изменится:

Кнопка станет без стандартной рамки (владельческая отрисовка) и получит статический край.

Текстовое поле станет многострочным с вертикальной прокруткой.

Статический текст получит рамку.

Примечания
Если второе приложение не находит окно, убедитесь, что первое приложение ещё запущено и окно не свёрнуто.

Второе приложение завершается сразу после изменения стилей (можно добавить Console.ReadKey() для паузы, если нужно увидеть результат в консоли, но по условию мы убрали лишнее).
